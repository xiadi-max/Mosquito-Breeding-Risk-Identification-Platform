# M6 简单验证

M6 完成 v2.2 页面真实 API 联调、同源页面托管、生产/演示模式隔离、安全与契约测试，以及 Windows 启动脚本。

## 1. 一键自动验证

打开 Anaconda Prompt：

```bat
conda activate mosquito311-yolov13
cd /d E:\vibecoding\蚊媒识别\codex-v2\v2.2\backend
python -m pip install -e ".[dev]"
python scripts\run_m6_validation.py
```

成功时最后显示：

```text
M6 validation passed: frontend API mode, contracts, security, M1-M5 E2E, deployment scripts
```

该命令会运行完整 pytest、M1-M5 HTTP 全流程，并使用无头浏览器检查首页 API 模式。如果本机没有随 Codex 提供的浏览器运行时，浏览器检查会明确显示 skipped，其余验证仍会执行。

## 2. 启动完整系统

在 Anaconda Prompt 执行：

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start_m6.ps1
```

看到 `Open in browser: http://127.0.0.1:8000/` 后，在浏览器打开：

```text
http://127.0.0.1:8000/
```

页面右下角应显示 `API · DEVELOPMENT`，表示正在使用真实后端。脚本同时启动 API 和 Worker，按 `Ctrl+C` 停止。

## 3. 演示模式

开发环境需要查看原演示数据时打开：

```text
http://127.0.0.1:8000/?demo=1
```

生产环境会禁用 `test_data.js`，不能启用演示模式。API 失败时页面显示真实错误和请求编号，不会自动回落到假成功。

## 4. 手工验收建议

1. 新建任务并上传至少 2 张同一连续区域的 JPG/JPEG/PNG。
2. 完成拼接、ROI、网格和推理。
3. 处理所有待复核项，再计算风险。
4. 生成并编辑处置建议。
5. 分别下载 CSV、Excel 和 PDF。
6. 刷新页面，确认任务与结果仍然存在。

当前默认拼接配置使用 OpenCV SCANS，默认检测配置仍使用 Fake Detector，便于无模型、无 GPU 环境完成全流程。生产配置不得使用 Fake Provider 冒充真实结果。拼接专项验证见 `OpenCV拼接-简单验证.md`。
