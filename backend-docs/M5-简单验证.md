# M5 简单验证

M5 新增风险分析、热点、规则处置建议、建议版本编辑，以及 CSV/XLSX/PDF 导出。

## 1. 更新环境与数据库

```bat
conda activate mosquito311
cd /d E:\vibecoding\蚊媒识别\codex-v2\v2.2\backend
python -m pip install -e ".[dev]"
python -m alembic upgrade head
python -m alembic current
```

应看到 `20260813_0006 (head)`。

## 2. 一键验证（推荐）

```bat
python scripts\run_m5_validation.py
```

脚本会自动启动临时 API、执行 M1-M5 全流程、删除临时任务并关闭 API，不需要再开第二个窗口。

成功时显示：

```text
M5 smoke test passed: risk, hotspots, rules decision, CSV/XLSX/PDF, 100% progress, cleanup
```

如需保留导出样本，可执行：

```bat
python scripts\run_m5_validation.py --output-dir data\m5-validation
```

## 3. 可选自动化测试

```bat
python -m pytest -q
```

预期至少 `52 passed`。Starlette 的 DeprecationWarning 不代表失败。

## 说明

- 风险分析前必须处理完所有 pending 复核项，否则返回 `PENDING_REVIEWS`。
- CSV 使用 UTF-8 BOM；XLSX 包含任务汇总、类别统计、热点、检测明细、审计参数；PDF 嵌入中文字体，并包含带 H01/H02 编号的结果定位图、编号和近似边界说明。
- 默认建议 Provider 是离线 `rules`，不需要 OpenAI API。
- 如果 PDF 提示字体未配置，请确认 Windows 字体目录存在微软雅黑、宋体或黑体。
