# M3 简单验证

M3 新增 ROI 版本管理、几何校验、640×640 网格预览、网格作业持久化，以及上游变化后的派生数据失效传播。

## 1. 打开 Anaconda Prompt

```powershell
conda activate mosquito311
cd /d E:\vibecoding\蚊媒识别\codex-v2\v2.2\backend
```

如果是在普通 PowerShell 中，第二条命令改成：

```powershell
Set-Location -LiteralPath 'E:\vibecoding\蚊媒识别\codex-v2\v2.2\backend'
```

## 2. 更新依赖和数据库

```powershell
python -m pip install -e ".[dev]"
python -m alembic upgrade head
```

确认迁移版本：

```powershell
python -m alembic current
```

应看到：

```text
20260813_0004 (head)
```

## 3. 启动 API

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

保持这个窗口不要关闭。

## 4. 一键验证 M3

再打开一个 Anaconda Prompt，重新执行第 1 步，然后执行：

```powershell
python scripts\m3_smoke_test.py
```

看到以下内容即表示完整流程通过：

```text
M3 smoke test passed: mosaic, ROI version, grid preview, grid worker, 57% progress, dashboard, cleanup
```

脚本会自动创建和删除临时任务，不会留下测试任务。

## 5. 可选：运行全部自动化测试

```powershell
python -m pytest -q
```

预期结果：

```text
41 passed
```

Starlette 的 `DeprecationWarning` 是上游依赖提示，不代表测试失败。

## 常见问题

- 提示无法连接 `127.0.0.1:8000`：第 3 步的 API 没有启动，或窗口已关闭。
- 提示数据库不是 M3 版本：重新执行 `python -m alembic upgrade head`，然后重启 API。
- 提示缺少 `shapely`：执行 `python -m pip install -e ".[dev]"`。
- 端口 8000 被占用：API 改用 `--port 8001`，验证命令使用 `python scripts\m3_smoke_test.py --base-url http://127.0.0.1:8001`。
