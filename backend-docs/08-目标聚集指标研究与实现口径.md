# 目标聚集指标研究与实现口径

## 结论

正式的登革热媒介伊蚊幼虫密度监测应优先使用布雷图指数（Breteau Index, BI）：

```text
BI = 伊蚊幼虫或蛹阳性容器数 / 调查户数 × 100
```

但本系统当前只有航拍影像中经人工复核保留的“潜在孳生容器”点位，没有调查户数，也没有幼虫/蛹阳性的现场鉴定结果，因此不能把图像检测结果命名为 BI、蚊媒密度或疾病风险概率。

本阶段采用与现有证据匹配的“目标聚集指数”：对经复核目标的 KDE 栅格值按本次 risk run 的峰值归一化到 0–100，用于定位任务内部的相对聚集区域。区域卡片直接展示该指数，40/75 分别作为中聚集和高聚集起始值，二者使用同一数值口径。

```text
目标聚集指数(x) = KDE(x) / max(KDE) × 100
```

该指数不是流行病学风险指数，不能替代 BI，也不能跨任务、跨日期直接比较。

## 研究与规范依据

1. 中国疾控《登革热媒介伊蚊监测指南》把 BI 定义为“阳性容器数 / 调查户数 × 100”，并要求入户检查积水容器及幼虫孳生情况；该指南还把 BI 或诱蚊诱卵器指数大于 20 作为暴发高风险提示。[中国疾控监测指南（PDF）](https://www.chinacdc.cn/jkyj/crb2/yl/dgr/jswj_dgr/202409/P020240906536498883520.pdf)
2. 《登革热防控方案（2025年版）》继续以 BI 小于 5 作为媒介控制目标，并结合成蚊密度判断应急监测终止条件，说明疾病传播风险不能由一个航拍图像分数单独替代。[国家疾控局防控方案](https://www.ndcpa.gov.cn/jbkzzx/c100014/common/content/content_1938557342511960064.html)
3. 2024 年发表于 *Acta Tropica* 的中国 UAV-AI 研究使用 YOLOv7 识别白纹伊蚊潜在孳生地，并通过 kernel density value 标出潜在孳生地密度最高、最需清除的子区域。这与本系统“检测点 → KDE → 重点检查区域”的数据条件相符。[研究论文](https://doi.org/10.1016/j.actatropica.2024.107234)
4. 一项 UAV 屋顶积水容器监测研究把航拍识别作为现场监测的补充，并对部分住户开展现场验证后再计算昆虫学指数；这进一步支持“潜在容器聚集”和“经现场确认的蚊媒指数”应分开表达。[研究全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13056549/)
5. PLOS One 的媒介研究将 BI、房屋指数、容器指数用于蚊媒调查，同时用 KDE 显示空间热点；它把昆虫学指标与空间聚集图作为不同层次的证据。[研究全文](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0295317)

## 产品口径

| 项目 | 当前采用 | 解释限制 |
|---|---|---|
| 区域主指标 | 目标聚集指数（0–100） | 当前任务 KDE 峰值归一化 |
| 分级 | 中聚集 ≥ 40；高聚集 ≥ 75 | 仅用于同一 risk run 的区域筛选 |
| 区域目标数 | 人工复核保留目标数 | 是模型检测证据，不等于阳性容器数 |
| 像素面积 | 仅用于几何、渲染和坐标换算 | 不生成“个/像素²”业务密度 |
| 米制面积 | 仅在可靠地理标定后展示 | 可增补“个/公顷”，但仍不等于 BI |
| 布雷图指数 | 当前不计算 | 需调查户数和现场确认的阳性容器数 |

## 实现映射

- 数据库存储字段：`hotspots.clustering_index`、`hotspots.clustering_level`。
- API：`hotspots[].clustering_index` 与 `thresholds.medium/high` 同口径；`metric` 明确归一化范围和不可跨 run 比较。
- 前端：区域卡片、图例、滑块、解释文案统一使用“目标聚集指数/聚集指数分界”。
- 建议：按 `clustering_level` 生成 P1/P2，并明确指数不是疾病概率或 BI。
- 导出：XLSX/PDF 输出目标聚集指数、聚集等级及口径说明，移除区域像素密度。
- 兼容：数据库迁移把旧 `score/risk_level` 重命名为新字段；前端只为旧 API 响应保留只读兼容回退。

## 后续升级条件

若要输出公共卫生意义上的风险分级，应新增现场调查数据：调查户数、积水容器总数、幼虫/蛹阳性容器数、调查日期和空间单元。届时 BI 应作为独立昆虫学指标进入风险模型，目标聚集指数继续负责航拍点位的空间定位，二者不可互相改名代替。
