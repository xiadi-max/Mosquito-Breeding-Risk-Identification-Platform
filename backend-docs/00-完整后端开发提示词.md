【二、产品目标与业务闭环】

实现以下七阶段任务流：

1. 创建、查询、搜索、筛选、切换、归档和删除巡查任务；
2. 批量上传同一区域 JPG/JPEG/PNG，校验数量、单文件大小、真实 MIME、哈希、EXIF GPS 和拍摄时间；
3. 异步生成 OpenCV SCANS 像素级拼接图并保存质量摘要；
4. 在拼接图上持久化一个或多个 ROI 多边形，支持覆盖式保存与乐观锁；
5. 按 640×640、0%–50% 重叠率在 ROI 内生成网格，边缘补边，并持久化网格元数据；
6. 用自训练 YOLOv13 推理，跨网格坐标还原和 NMS 去重，把低置信候选进入人工复核；
7. 根据最终检测点执行 KDE/目标聚集区域分析，输出类别统计、聚集分级、可编辑 AI 处置建议及 CSV/XLSX/PDF 报告。

每个任务的数据严格隔离。工作流结果自动保存，可返回前一步修改。修改上游输入后，下游结果必须标记 stale，不得继续展示为当前有效版本。

【三、必须采用的 MVP 架构】

1. Python 3.11；FastAPI；Pydantic Settings；SQLAlchemy 2.x；Alembic；pytest。
2. 模块化单体，不拆微服务。API 进程与计算 Worker 分进程，共享同一 SQLite 数据库和本地 artifacts 根目录。
3. SQLite 开启 WAL、foreign_keys、busy_timeout；事务要短。不要把二进制影像存入数据库。
4. 不引入 Redis/Celery。实现数据库作业队列：queued → claimed → running → succeeded/failed/canceled；包含租约、心跳、重试、超时、取消、失败原因和重启恢复。
5. 进度写入 job_events，通过 SSE 推送。SSE 支持 event id、Last-Event-ID、15 秒心跳和断线续传；同时保留 GET job 轮询兜底。
6. 文件存本地，数据库只存相对于 STORAGE_ROOT 的 POSIX 相对路径、SHA-256、MIME、字节数、宽高和 artifact 类型。任何用户输入都不能直接拼接成服务器路径。
7. 拼接实现 MosaicEngine 协议：FakeMosaicEngine 供测试；OpenCVMosaicEngine 使用 SCANS 仿射模型承担正式拼接。至少 2 张重叠影像，默认工作尺度 0.6、置信阈值 0.3，完成曝光/接缝融合并裁黑边；不要把像素级拼接图宣称为测绘级正射成果。
8. 推理实现 Detector 协议。YoloV13Detector 从配置加载固定权重路径，启动时记录模型 SHA-256、类别表、设备和版本。实现 FakeDetector 供测试。不要允许 API 请求传任意权重路径。
9. AI 建议实现 DecisionProvider 协议。默认 RuleBasedDecisionProvider 必须在无网络时可用；可选 OpenAICompatibleDecisionProvider 只接收结构化统计与人工上下文，不上传原始影像。输出先过 Pydantic schema，保存生成版本、人工编辑版本和 evidence snapshot。
10. API 统一前缀 /api/v1；另提供 GET /api/mosquito-workbench/dashboard 作为当前 data.js 的兼容门面。

- 0%：任务创建；

- 42%：至少一个有效 ROI 已保存；
- 57%：网格生成成功；
- 71%：推理成功；
- 85%：风险分析成功且待复核为 0（若仍有待复核，保持 71% 并返回 blocked_by）；
- 100%：至少一个有效的决策建议版本或完整报告已生成。

【六、坐标、网格和空间数据规范】

前端 SVG 的 900×545、900×520 仅为展示坐标。后端 canonical 坐标必须是拼接图 native pixel 坐标，左上角原点，x 向右、y 向下，并同时保存 source_width/source_height。前端保存 ROI 前进行：

native_x = svg_x / svg_viewbox_width * mosaic_width
native_y = svg_y / svg_viewbox_height * mosaic_height

API 返回 native pixel polygon；前端展示时做逆变换。坐标不得因缩放/平移后的 CSS transform 而漂移。

当前 OpenCV SCANS 产物不带地理参考，artifact 的 CRS 和 affine transform 保持为空。若未来引入经独立验收的地理参考 Provider，才可派生 WGS84 GeoJSON；不允许仅凭 EXIF 点位伪造精确地理边界。

ROI 校验：至少 3 个不同顶点；自动闭合；坐标在图像边界内；拒绝 NaN/Infinity；检测并拒绝明显自交多边形；保存面积（pixel²，若有 GSD 再给 m²）。

网格：固定模型输入 640×640；默认 overlap=0.20；step=round(640*(1-overlap))；网格覆盖 ROI 包围盒并按 polygon intersection 过滤；边缘以 letterbox/pad 补齐，记录 source_box、padding、tile_to_mosaic 变换。检测框从 tile 映射回 mosaic 后，再跨 tile 做 class-aware NMS，默认 IoU=0.45。所有阈值来自后端配置或本次 run 快照，不能散落硬编码。

置信度先使用：infer_min=0.20；review_threshold=0.50；auto_accept_threshold=0.80。0.20–0.80 进入待复核，≥0.80 自动保留，<0.20 丢弃。该规则必须配置化并在报告中显示，后续由疾控方确认。

【八、上传与文件安全】

- 默认最多 50 张/批、50 MiB/张、任务总量上限配置化；
- 文件扩展名不可信，用 magic bytes/Pillow/OpenCV 解码共同校验；
- 流式写临时文件并同步计算 SHA-256，成功后原子 rename；失败清理临时文件；
- 不把完整客户端文件名用作磁盘名；仅作为 display_name 保存，输出 HTML/PDF 前转义；
- 拒绝路径穿越、SVG、可执行文件、图像解压炸弹和异常像素尺寸；
- EXIF 解析失败只标 warning，不让整个批次崩溃；
- 相同 task + SHA-256 默认去重，响应中说明 duplicated；
- artifact 下载做任务归属校验，Content-Type 和 Content-Disposition 固定由服务器生成。

【九、图像处理、推理和风险计算】

拼接 job 分步：preflight → load_images → feature_registration → seam_blending → render → quality_check → persist。输出包括 JPEG preview、JPEG mosaic、width、height、源影像数、GPS 完整率、异常影像、策略名与参数快照。

正式拼接使用 OpenCV `Stitcher_SCANS` 仿射模型。输入限制为至少 2 张 JPG/JPEG/PNG，来自同一连续、近似共面且重叠充分的区域。默认不对单张原图强制去噪、增强或锐化；Stitcher 自带曝光补偿和接缝融合，完成后裁掉纯黑画布。

推理 job 分步：load_model → load_tiles → detect → map_coordinates → class_aware_nms → persist → build_review_queue。原始 tile detections 可写 JSON artifact，数据库保存去重后的 task-level detections。记录每个框的 class_id/name、confidence、tile_box、mosaic_box、source_grid_id、model_version_id、review_state。

风险 run 的输入只能是 effective accepted detections。实现可测试的基础算法：检测点中心 → KDE 密度栅格 → 以本次任务峰值归一化为 0–100 的“目标聚集指数” → 聚集指数分级 → 等值线/连通域聚合成 hotspot。保存 bandwidth、resolution、thresholds、输入检测数量和算法版本。目标聚集指数仅用于本次任务内部定位，不是疾病概率、布雷图指数，也不能跨任务直接比较。没有足够点时返回空热点和明确说明，不能制造热点。

目标聚集指数分界默认 high=75、medium=40，强制 0<=medium<high<=100。返回重点检查区域的 polygon/centroid、clustering_index、clustering_level、target_count、dominant_category。区域按聚集指数从高到低编号为 H01、H02……，同分时按拼接图从北到南、从西到东排序；编号只用于连接地图、表格和建议，重算后允许变化。像素面积只允许作为内部几何数据，不得换算或展示为“个/像素²”的业务密度；面积若无地理参考不得伪称 m²。

AI 建议必须只依据已保存证据：重点检查区域、目标聚集指数及分界、类别统计、复核结果、已标定的 ROI 面积以及人工 context。结构化输出含 title、priorities[]、evidence[]、disclaimer、provider、model、created_at。始终显示“AI 建议为辅助信息，最终处置决定由疾控专业人员确认”。用户编辑后另存新版本，不覆盖生成原文。

PDF/CSV/XLSX 导出必须异步、可重复下载。CSV 使用 UTF-8 BOM 便于中文 Excel 打开；XLSX 至少含任务汇总、类别统计、热点、检测明细、审计参数；PDF 使用可嵌入中文字体，首页必须嵌入带 H01/H02 等编号的结果定位图，并用通俗文字解释编号、边界、指数和处置建议。白色虚线仅是达到分界连通范围的近似外包边界，不得表述为目标框、屋顶或行政边界。生成后校验最小文件、页数和地图图像对象。报告不能引用未来会失效的临时 URL。

【十四、最终验收条件】
