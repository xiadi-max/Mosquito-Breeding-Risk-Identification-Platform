## 1. 打开 Anaconda Prompt

```powershell
conda activate mosquito311-yolov13
cd /d E:\vibecoding\蚊媒识别\codex-v2\v2.2\backend
```

```powershell
Set-Location -LiteralPath 'E:\vibecoding\蚊媒识别\codex-v2\v2.2\backend'
```


```powershell

```

## 关于真实 YOLOv13

默认 `DETECTOR_PROVIDER=fake`，因此一键验证不需要 GPU、网络或模型权重。

真实 YOLOv13 需要另外准备：

- 与项目模型兼容的 YOLOv13 运行环境；
- 经过业务训练或确认的 `.pt` 权重；
- `.env` 中设置 `DETECTOR_PROVIDER=yolov13`、`MODEL_WEIGHTS_PATH` 和 `MODEL_DEVICE`。

YOLOv13 的官方实现与安装说明：<https://github.com/iMoonLab/yolov13>。不要把未经业务训练的通用权重当成蚊媒识别模型。

## 常见问题

- 无法连接 `127.0.0.1:8000`：API 没启动或窗口已关闭。
- 数据库不是 M4：执行 `python -m alembic upgrade head` 后重启 API。
- 提示 `MODEL_NOT_CONFIGURED`：开发验证请保持 `DETECTOR_PROVIDER=fake`；真实模型则检查权重路径和 YOLOv13 运行库。
- 端口 8000 被占用：API 改用 `--port 8001`，验证使用 `python scripts\m4_smoke_test.py --base-url http://127.0.0.1:8001`。
